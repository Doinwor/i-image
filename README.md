# i. Image

**Редактор, конвертер и компрессор изображений прямо в браузере.**
Отдельный продукт студии і. — файлы не покидают устройство, серверов нет.

## Принцип

Все операции выполняются локально через Canvas API и File API. Ни один файл не
отправляется в сеть. Отсюда следствия: без лимитов на размер, без регистрации,
без рекламы, бесплатно навсегда и работает офлайн (PWA).

## Возможности

- Загрузка: drag&drop, выбор файлов, вставка из буфера (Ctrl+V), пакетно.
- Список файлов с миниатюрами, разрешением, размером и форматом.
- Правка: поворот на 90°, отражение по горизонтали/вертикали.
- Обрезка: выделение области мышкой.
- Изменение размера вручную + пресеты для соцсетей (Instagram, Stories, YouTube,
  TikTok, VK, аватар).
- Фильтры (неразрушающие): яркость, контраст, насыщенность, размытие, оттенок,
  ч/б, сепия, инверсия + готовые пресеты.
- Конвертация: PNG, JPEG, WebP, AVIF (если поддерживает браузер).
- Сжатие: ползунок качества и показ «было → стало» с процентом экономии.
- Экспорт: скачать по одному или всё сразу ZIP-архивом (свой writer, без библиотек).
- Сравнение «до/после», тёмная тема, история обработок, пользовательские пресеты.
- PWA: установка как приложение, офлайн-режим через Service Worker.

## Структура

```
image-toolbox/
├── index.html            // интерфейс приложения
├── css/
│   ├── style.css         // айдентика i. Image
│   └── dark-theme.css    // тёмная тема
├── js/
│   ├── main.js           // инициализация, состояние, интерфейс
│   ├── uploader.js       // загрузка файлов
│   ├── editor.js         // ядро: выбор, рендер, геометрия, история
│   ├── filters.js        // фильтры и цветокоррекция
│   ├── crop.js           // выделение области обрезки
│   ├── resize.js         // расчёт размеров
│   ├── convert.js        // конвертация форматов
│   ├── compress.js       // сборка выхода и сжатие
│   ├── export.js         // скачивание и ZIP
│   ├── presets.js        // пресеты и форматы
│   └── zip.js            // собственный ZIP-writer (STORE)
├── assets/
│   └── logo.svg
├── manifest.json         // PWA-манифест
└── sw.js                 // service worker
```

## Стек

Чистый HTML + CSS + JavaScript без фреймворков и без внешних библиотек.
Canvas API, File/Blob API, `ctx.filter`, Promise. Шрифты — Unbounded (бренд),
Inter (интерфейс), JetBrains Mono (цифры).

## Локальный запуск

Открыть `index.html` напрямую браузером — приложение работает и с файловой
системы (кроме Service Worker, для него нужен http/https). Для проверки PWA:

```
python -m http.server 8080
```

и открыть `http://localhost:8080/`.

## Деплой

Статика — подходит GitHub Pages / Netlify / Vercel. Никакого бэкенда не требуется.

## Заметки

- AVIF/WebP доступны только там, где браузер умеет их кодировать; недоступные
  форматы в списке помечаются как «недоступно».
- История хранится в памяти вкладки; пользовательские пресеты — в `localStorage`.
- Иконки в манифесте — SVG; для установки на iOS при необходимости добавить PNG.
